# BookBites

BookBites is a web application that provides concise summaries of popular books in both English and Arabic. It features a clean, responsive interface with dark mode support and language switching capabilities.

## Features

- **User Authentication**: Sign in, sign up, or continue as a guest
- **Book Summaries**: Detailed summaries of popular books
- **Bilingual Support**: All summaries available in both English and Arabic
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works on desktop and mobile devices
- **Search Functionality**: Find books by title or author

## Project Structure

- `index.html` - Sign-in page
- `signup.html` - Registration page
- `dashboard.html` - Main book listing page
- `book.html` - Detailed book page
- `css/style.css` - Main stylesheet
- `js/script.js` - Main JavaScript functionality
- `js/book-detail.js` - Book detail page functionality

## How to Use

1. Open `index.html` in your browser
2. Sign in, sign up, or continue as a guest
3. Browse the book summaries on the dashboard
4. Click on any book to view its detailed summary
5. Toggle between English and Arabic using the language switcher
6. Toggle between light and dark mode using the theme toggle

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)
- Font Awesome for icons
- Responsive design principles
